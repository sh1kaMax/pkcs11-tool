# PKCS11 Token Studio

Кроссплатформенное GUI-приложение на Rust для работы с Рутокенами через PKCS#11.

## Что умеет

- показывать список подключенных токенов;
- логиниться в токен как пользователь;
- форматировать токен через удаление пользовательских объектов;
- менять PIN пользователя;
- записывать файл на токен как `DATA`-объект;
- читать список объектов с токена и выгружать выбранный объект в файл;
- показывать уведомления об успехе и ошибках в правом верхнем углу.

## Стек

- `eframe` / `egui` для GUI;
- `cryptoki` для работы с PKCS#11;
- `rfd` для системных диалогов выбора файлов.

## Важные замечания

- Для подключения к Рутокену нужен установленный PKCS#11-модуль. По умолчанию приложение пробует типичные пути для Linux и Windows, но путь можно изменить на стартовом экране.
- Команда форматирования реализована как очистка пользовательских объектов токена после входа пользователя. Полный заводской сброс может требовать отдельные административные права или вендорские инструменты.
- Локальная сборка этим изменением не проверялась по вашему требованию.
